ROBOTICS

Robotic Hand

An investigation into mechanical design, electronics and control systems, built from the ground up as a hand-shaped robot — and the starting point for a longer-term research direction into self-reconfigurable robotics.

STATUS: BUILDING... LOG_ID: 001 LAST_UPDATE: IN PROGRESS
// 01

Overview

This project explores the creation of a robotic hand using electronic components, motors and custom mechanical parts. The build covers mechanical design, actuation, wiring and the software controlling individual finger movement.

It's the first physical step toward a broader question I want to keep investigating: what does it take for a robot to move, adapt, and respond to the world around it — not just perform one fixed task.

// 02

Research Direction — Project CHAMELEON

A robot should not be a machine built for one purpose. It should be a system capable of becoming whatever machine is needed.

Core research question: can a collection of simple robotic modules autonomously reorganise their physical structure to survive and complete unknown tasks in changing environments?

Most robots today are designed for one job and fail the moment conditions change outside that design. This project asks whether that has to be true:

Human designs robot
↓
Robot is manufactured
↓
Robot performs one specific task
↓
Robot fails outside its design

The proposed alternative:

Environment changes
↓
Robot understands the problem
↓
Robot chooses a new body configuration
↓
Modules reorganise
↓
New configuration performs the task

ADAPTIVE MORPHOLOGY

How does a system decide what shape to become for an unknown problem?

SELF-ORGANISATION

Can complex structure emerge from simple modules with only local awareness, no central controller?

SELF-REPAIR

If part of the system fails, can the rest detect it, rearrange, and keep going?

ENERGY OPTIMISATION

Judging a configuration not just by success, but by efficiency, stability and speed.
