Research Direction

Project CHAMELEON

A robot should not be a machine built for one purpose — it should be a system capable of becoming whatever machine is needed.

Exploring whether simple robotic modules can autonomously reorganise their own physical structure to solve unknown tasks in changing environments — self-reconfigurable modular robotics, inspired by adaptive machines like Baymax.
